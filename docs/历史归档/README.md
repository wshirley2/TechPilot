## 时间线保护规则

1. 归档文件保持原文，不批量改写其中的历史状态；
2. 需要恢复某项设计时，先与当前代码和架构说明核对；
3. 只把仍有效的结论提炼到当前文档，不整段复制旧“当前状态”；
4. 旧测试数字只代表当时验证，不代表今天；
5. 新文档出现冲突时，以实际代码/测试事实为先，再修正文档。
